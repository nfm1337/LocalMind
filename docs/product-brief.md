# LocalMind Product Brief

LocalMind is a privacy-first Android app for local semantic search and offline Q&A over personal notes.

## Problem

People save useful information in notes but cannot reliably find it later by meaning.

## Target User

Developers, students and power users who want private offline access to their personal knowledge.

## MVP

- Create and edit local notes
- Generate local embeddings
- Search notes by meaning
- Ask questions over notes
- Show answers with source notes

## Non-goals for MVP

- Cloud sync
- Login
- PDF/OCR
- Collaboration
- Rich text editor
- ObjectBox/vector database
- Background indexing
- Complex chunking

## Success Criteria

A user can create several notes, ask a question, and receive a relevant answer with source notes on-device.
